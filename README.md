# Numerical-Analysis

a project of the programs used in the college subject "Numerical Analysis" in physics major, it includes methods of calculus which requires programming.
the code is written in python, make sure to have the libraries "numpy", "sympy" and "scipy" installed otherwise the code might not work as intended.
the code is flawed and unfinished, but for some methods the code works just fine or would with some tweaks.
since I was done with the subject I didn't invest more time polishing the code.
feel free to use, revamp the code as desired or release a more complete version of it on your own.
