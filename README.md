# Numerical-Analysis

a project of the programs used in the college subject "Numerical Analysis" in physics major.
This repository contains Python implementations developed for a university Numerical Analysis course in the Physics program. The project explores numerical methods for calculus and demonstrate the application of computational techniques to mathematical problems. Some implementations are course-level projects and may require further refinement or adaptation.

make sure to have the libraries "numpy", "sympy" and "scipy" installed otherwise the code might not work as intended.

feel free to use and refine the code as desired.
